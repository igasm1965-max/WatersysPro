# План создания графической электросхемы WaterSysPro

## Цель
Создать набор графических электросхем (SVG) для проекта WaterSysPro на основе распиновки из [`include/config.h`](../include/config.h:191).

## Формат
**SVG** (Scalable Vector Graphics) — поскольку Fritzing не установлен в системе, а .fzz — бинарный XML-формат, который невозможно корректно сгенерировать без самого Fritzing. SVG можно:
- Открыть в любом браузере
- Встроить в документацию (.md)
- Конвертировать в PNG/PDF при необходимости
- Редактировать в любом векторном редакторе (Inkscape, Illustrator)

## Структура файлов

Все схемы разместить в директории `docs/schematics/`:

```
docs/schematics/
├── README.md                    # Индекс со ссылками на все схемы
├── full_system.svg              # Полная электросхема системы
├── power.svg                    # Схема питания
├── esp32_main.svg               # ESP32 и основные подключения
├── relays.svg                   # Схема подключения реле (6 шт)
├── sensors_ultrasonic.svg       # Ультразвуковые датчики HC-SR04
├── i2c_bus.svg                  # I2C шина: LCD 20x4 + RTC DS3231
├── encoder.svg                  # Энкодер с кнопкой
├── sd_card.svg                  # SD-карта (SPI mode)
└── pinout_table.svg             # Таблица распиновки GPIO
```

## Содержание каждой схемы

### 1. `full_system.svg` — Полная электросхема
- ESP32 Dev Module в центре
- Все подключенные модули вокруг
- Линии соединений с подписями GPIO
- Цветовая кодировка: красный — питание, черный — GND, синий — сигнальные линии
- Легенда

### 2. `power.svg` — Схема питания
- Входное питание (12V/24V от источника)
- Преобразователь 12V→5V (если есть)
- Преобразователь 5V→3.3V (для ESP32, SD, датчиков)
- Развязка питания реле (опторазвязка или транзисторные ключи)
- Предохранители и защита

### 3. `esp32_main.svg` — ESP32 и основные подключения
- Плата ESP32 Dev Module
- GPIO2 → встроенный LED
- GPIO32,34,35 → энкодер
- GPIO21,22 → I2C
- GPIO4,19,23,33,39 → SD SPI
- GPIO16,17,5,18 → HC-SR04
- GPIO13,12,14,27,26,25 → реле

### 4. `relays.svg` — Реле (6 шт)
- 6 релейных модулей (SRD-05VDC или аналоги)
- GPIO13 → PUMP1 (насос наполнения)
- GPIO12 → PUMP2 (насос фильтрации)
- GPIO14 → AERATION (аэрация)
- GPIO27 → OZONE (озонатор)
- GPIO26 → FILTER (фильтр)
- GPIO25 → BACKWASH (обратная промывка)
- Питание реле через транзисторный ключ (2N2222 или ULN2003)
- Защитные диоды (1N4007) параллельно катушкам

### 5. `sensors_ultrasonic.svg` — Ультразвуковые датчики
- 2 × HC-SR04
- Датчик 1: TRIG=GPIO16, ECHO=GPIO17 (бак 1)
- Датчик 2: TRIG=GPIO5, ECHO=GPIO18 (бак 2)
- Питание VCC=5V, GND
- Делители напряжения на ECHO (5V→3.3V) через резисторный делитель

### 6. `i2c_bus.svg` — I2C шина
- SDA=GPIO21, SCL=GPIO22
- LCD 20x4 (I2C, адрес 0x27)
- RTC DS3231 (I2C, адрес 0x68)
- Подтягивающие резисторы 4.7кОм на SDA и SCL к 3.3V

### 7. `encoder.svg` — Энкодер
- KY-040 или аналогичный
- CLK=GPIO35 (инвертирован)
- DT=GPIO34 (инвертирован)
- SW=GPIO32 (кнопка)
- VCC=3.3V, GND
- Подтягивающие резисторы 10кОм на CLK, DT, SW к 3.3V

### 8. `sd_card.svg` — SD-карта (SPI)
- SCK=GPIO4
- MISO=GPIO19
- MOSI=GPIO23
- CS=GPIO33
- CD=GPIO39 (опционально)
- VCC=3.3V (обязательно, не 5V!)
- Подтягивающие резисторы 10кОм на MISO, CS, CD

### 9. `pinout_table.svg` — Таблица распиновки
- Полная таблица всех GPIO с назначением
- Удобно для печати

## Технические требования к SVG

1. **Размер холста**: 800x600px для отдельных схем, 1200x800px для полной схемы
2. **Цветовая схема**:
   - Фон: #FAFAFA (светло-серый)
   - Линии питания: #D32F2F (красный)
   - Линии GND: #212121 (черный)
   - Сигнальные линии: #1565C0 (синий)
   - I2C линии: #2E7D32 (зеленый)
   - Текст: #212121
   - Заголовки: #1565C0
3. **Шрифты**: sans-serif (Arial, Helvetica)
4. **Стиль линий**: stroke-width=2 для сигнальных, stroke-width=3 для питания
5. **Компоненты**: прямоугольники со скругленными углами (rx=5), с текстовыми подписями
6. **Подписи пинов**: текст рядом с линией, например "GPIO13"

## Процесс реализации

1. Создать директорию `docs/schematics/`
2. Создать каждый SVG-файл по отдельности
3. Создать индексный `README.md`
4. Проверить отображение в браузере

## Примечания

- Все схемы должны быть самодокументированными (с легендой)
- Использовать viewBox для масштабирования
- Комментарии в SVG на русском/английском
- Файлы должны открываться в любом современном браузере
